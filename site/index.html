One operational surface

The tools you reach for when the server is alive.

Keep routine administration understandable, auditable, and close to the community it serves.

01 / CONTROL

Live administration

Poll server status, manage survivors, broadcast announcements, run guarded commands, save, reload options, and shut down safely.

02 / PEOPLE

Survivor records

Track observed sessions and playtime, review online state, and help players through a private request center with staff assignment and replies.

03 / SIGNAL

Deep telemetry

Add health, kills, skills, traits, position, profession, carried weight, and current vehicle key data through the separate server companion.

04 / MAP

Interactive world map

See reported survivor positions on a pinned Build 42.19 map. Player views follow their latest movement while staff can review the wider field.

05 / ACCESS

Player portal

Optionally let survivors sign in with their Project Zomboid account, see their private record, choose a theme, and contact server staff.

06 / TRACE

Audited actions

Record administrative actions while redacting secret-bearing commands. User, Moderator, and Admin roles keep access intentionally scoped.

From zero to connected

Start with one container.

No plaintext environment file is required. The first-run screen collects and encrypts the values on the server.

Run the image

Deploy ghcr.io/doomedgaming/pz-rcon-admin:latest with a persistent data volume and your chosen bind address.

Open secure setup

Use the one-time URL from the container logs, enter RCON credentials, and add optional telemetry or player sign-in.

Operate

The container restarts with encrypted settings. Open the player portal at / or the control console at /admin.

Credentials stay home

Built to be self-hosted, not data-hungry.

✓
Encrypted first-run configuration

Passwords, session keys, FTP credentials, and tokens are encrypted with AES-256-GCM and never returned to the browser after saving.

✓
Unprivileged container

The published image runs as a non-root user with a read-only filesystem, dropped capabilities, and a persistent data volume.

✓
No telemetry credentials in the mod

The Lua companion only writes a local JSON snapshot. It contains no passwords, dashboard URL, or outbound networking code.

✓
Your network policy still matters

Use HTTPS for public access, restrict RCON and FTP at the firewall, and prefer FTPS or a private network when your host supports it.
